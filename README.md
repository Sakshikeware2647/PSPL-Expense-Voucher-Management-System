# PSPL Expense Voucher Management System

## Project Overview
A full-stack web application developed as part of an internship assignment to manage expense vouchers.

## Technologies Used
- Frontend: React.js, Vite, CSS
- Backend: Node.js, Express.js
- Database: SQLite (better-sqlite3)

## Features
- Expense voucher management
- Frontend and backend architecture
- API-based communication

## Installation
1. Install Node.js.
2. Install dependencies using `npm install` in the appropriate project folders.
3. Configure environment variables using `.env.example`.
4. Start the frontend and backend using their respective scripts.
